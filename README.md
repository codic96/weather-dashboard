# 🌤️ SkyCast - Weather Dashboard

SkyCast is a modern, responsive weather dashboard built using vanilla web technologies. It leverages the OpenWeatherMap API to display current conditions and a 5-day weather forecast.

## Features
- Search weather by any city name globally.
- Persistent Light/Dark theme configuration.
- Caches the last 5 searched cities using browser `localStorage`.
- Fully responsive across desktop, tablet, and mobile displays.

## Setup Instructions
1. Extract the contents of this zip archive into a folder.
2. The active API key has already been pre-configured inside `script.js`.
3. Simply double-click or open `index.html` in your web browser to run the application immediately!
